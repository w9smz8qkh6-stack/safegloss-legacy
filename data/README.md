# Local standards data

Standards PDFs, catalogs, extracted JSON, and other source or derived datasets
are intentionally excluded from the public repository. Keep locally obtained
material under this directory; Git ignores everything here except this file.

Several management commands under `core/management/commands/` expect local
files in `data/` or `data/seeds/`. Supply only material that you are authorized
to use, and do not commit it.
